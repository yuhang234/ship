每次想要"重新搭一个博客"，真正的问题其实不是用什么框架，而是：**这东西一年会向我索取多少**。

## 钱

- 域名：一年几十块（可选）。
- 托管：GitHub Pages，0 元。
- 构建：GitHub Actions 免费额度足够个人博客，0 元。
- 登录代理：Cloudflare Workers 免费额度，0 元。
- 数据库：没有。0 元。

一共 0 元。需要的只是一个 GitHub 账号。

## 注意力

比钱更贵的部分是注意力。我列了一下会消耗注意力的地方：

1. 依赖升级。静态站没有服务端，升级失败也只影响构建，不影响线上。
2. 登录服务。OAuth 代理是个免费 Worker，一次配好，长期不动。
3. 部署失败。Actions 失败会有邮件，通常只是某篇文章 frontmatter 写错。
4. 备份。仓库本身就是备份，每台设备 clone 一份即可。

加起来大概一年两三次"需要处理"的时刻。这个量级我可以接受。

## 代价

没有数据库，所以没有评论、没有阅读统计、没有"在线编辑多人协作"。这些我都不要。

用 Markdown 文件 + Git 提交换来的，是内容的所有权。这笔交易我觉得划算。

> 判断一个技术方案，不看它能做什么，而看它要求你长期维护什么。
